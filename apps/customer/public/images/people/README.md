# Reviewer avatars

Drop art into this folder, named exactly as listed below, and testimonials
(desktop + mobile home) pick it up automatically — the fallback reviews map
to `avatar-01..03`, and any missing file degrades to the initials circle.

No `pnpm sync:images` needed — avatars stay customer-app-only.

## Expected files

| # | Filename | Spec |
|---:|---|---|
| 1 | `avatar-01.webp` | 256×256 px square, ≤ 15 KB |
| 2 | `avatar-02.webp` | 256×256 px square, ≤ 15 KB |
| 3 | `avatar-03.webp` | 256×256 px square, ≤ 15 KB |
| 4 | `avatar-04.webp` | 256×256 px square, ≤ 15 KB |
| 5 | `avatar-05.webp` | 256×256 px square, ≤ 15 KB |
| 6 | `avatar-06.webp` | 256×256 px square, ≤ 15 KB |
| 7 | `avatar-07.webp` | 256×256 px square, ≤ 15 KB |
| 8 | `avatar-08.webp` | 256×256 px square, ≤ 15 KB |

Content: diverse, warm-lit, UK-plausible faces (AI-generated is fine — must
NOT be real identifiable people unless licensed), neutral background,
genuine relaxed expressions. No stock-photo gloss.

Full spec: `docs/design-asset-guide.md` §3g.
